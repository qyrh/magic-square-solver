幻方求解器

任意阶（1–8）· 整数 / 分数 / 小数（精确有理数运算）· 输入即出数：凡能确定的格子全部推出，按“最少已知数优先”给出填数顺序与最简证明 · 点击推出的数可查看依据 · 分页 / 整页 / 打印 PDF / 导出 DOCX

① 输入幻方

提示：填满 9 个数即可（可用分数/负数，如 -3 0.5 2/3 …）。
每个格子可填：整数（如 12）、分数（如 1/2、10/4）、小数（如 0.75）、甚至 1.5/2；留空 = 未知。能确定的数会自动回填到填写框（绿色斜体 = 自动推出，直接输入可把它改成已知数，双击可查看证明）；黑色 = 你输入的已知数。↩ 撤回 / ↪ 重做（Ctrl+Z / Ctrl+Y）可回退任何填写操作。输出自动选有效数字更少的表示（平手取最简分数），图中分数以上下分式呈现。
值域限定：选「1…n²」或「自定义集合」时，程序先用“n 条行线之和 = nS = 全部数字之和”直接算出幻和，再据幻和逐步推出；并在限定范围内穷举所有合法填法，用“该格在所有填法中都等于同一个值”来证明某格确定（也用于发现无解，如 1…9 时角格不可能是 1）。选「只允许整数」时，程序检查可确定的数是否都是整数，并尝试构造整数填法作为见证；若只能取分数则报告无解（如三阶 a=1, i=2 会使中心 = 3/2）。
示例：
1 / 1

提示：绿色（已推出）/ 黄色（本步新推出）的格子可点击，查看该数是根据哪几个数、依据什么结论推出的。打印时选择“另存为 PDF”即可导出 PDF。
