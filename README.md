# 幻方求解器 —— 任意阶 · 分数/小数 · 逐步最简证明

纯前端单页应用：给定任意阶（1–8）幻方的一部分数字，**输入即自动出数**——凡能被确定的格子全部推出
（哪怕只靠 2 个数能定出 1 个格子也会给出），按 **“需要已知数最少优先”** 的顺序逐步给出**最简证明**
（通俗文字 + 数学符号），**点击任何推出的数可查看它是根据哪几个数、依据什么结论推出的**。
最后给出填数顺序总表与验证表，支持分页浏览、一页全显、打印为 PDF、导出 DOCX。

## 使用（两种方式任选）

1. **单文件版（推荐，发给任何人）**：直接双击 `dist/幻方求解器.html` —— 全部代码已内联，
   无网络、无安装、无依赖，离线可用；
2. 源码版：双击根目录 `index.html`，或 `python -m http.server 8000` 后访问
   `http://127.0.0.1:8000/index.html`。

重新打包单文件版：`node build.js`（白名单内联四个脚本，产出 `dist/幻方求解器.html`）。

## 功能一览

- **任意阶（1–8）、任意填数**：留空即未知；已知数矛盾时明确报告“无解”。
- **输入即出数 + 自动回填**：勾选“输入即自动出数”（默认开）后，每填/改一个数字立即重新求解，
  **能确定的数自动回填到填写框**（绿色斜体 = 自动推出，直接输入可覆盖为已知数，双击可查看该数的证明）；
  求不出全部时照样把所有能确定的格子全部出数，并说明剩余自由参数、给出两种合法填法反例。
- **快速/完整两种视图**：输入时是快速模式（只出数不展示证明，状态条提示“能确定 X/Y 格”）；
  **点“求 解”后才给出完整逐步证明**，且**证明默认折叠**（点击展开，支持一键展开/折叠全部）。
- **撤回/重做**：任何填写操作（含预设、清空、自动回填后的整体状态）都可 ↩ 撤回 / ↪ 重做（Ctrl+Z / Ctrl+Y）。
- **最优证明搜索（技巧优先级）**：每步自动挑选最简单的技巧——能用幻和直出的优先；其次
  “两条线（有交叉）和相等，去掉交叉格，剩余部分之和相等”；再次“多线去交叉（容斥）”；
  最后才是一般加权组合。三阶会自动识别**马步定理**（2×角 = 马步两数之和，即“过角三线之和=3S
  与总和=3S 去交叉”的最优证法）等结论并命名。
- **值域限定（三种，求解与证明策略随之改变）**：
  - **1…n²（各用一次）**：先用“n 条行线之和 = nS = 1+…+n²”**直接求出幻和**（第 1 步），
    之后每一步都能直接用幻和（补线法），证明显著变短；
  - **只允许整数**：检查可确定的数是否都是整数（如三阶 a=1,i=2 → 中心 3/2 → 报无解），
    并搜索构造一组整数填法作为存在性见证；
  - **自定义数字集合**（恰好 n² 个，各用一次）：同样由总和直接得幻和，并可穷举验证。
- **穷举验证（3/4 阶限定模式）**：穷尽限定范围内所有合法填法，用“该格在所有填法中都等于同一值”
  证明它确定；用“存在两种不同填法”说明它不能确定（这就是“为什么某格能确定”的证明）。
- **证明复杂度优先**：候选证明按 ①技巧分级（幻和直用最先）②涉及行列数（系数按次数计入）
  ③涉及格子数 ④前提数 ⑤已命名定理 ⑥少除法 依次择优，避免“带系数的多行组合”这类复杂证明。
- **画块证明**：对“去交叉”类技巧给出红/蓝区域示意图（红格 = 蓝格 / 红格 = 蓝格 + c×S），
  通俗文字 + 字母证明并列；每步只标注该步涉及的格子字母。
- **随机试解验证**：总结页在解空间随机取 12 组满足已知条件的填法，“每次都相同的格子 = 可确定”
  与线性判定交叉验证（一致 ✓），直观印证“填别的数就无解”。
- **点击查阅**：绿色（已推出）/黄色（本步新出）格子可点击，弹窗展示：
  该数根据哪几个数（含来源：题设或第几步）、依据的定理名，以及完整证明与代入过程。
- **分数/小数**：输入支持 `3`、`-4`、`0.75`、`1/2`、`-3/4`、`2.5/3`；内部精确有理数运算；
  输出按“有效数字少者胜、平手取最简分数”选择显示；图中分数渲染为**上下分式（立体分数）**。
- **最少已知数优先的证明流**：每步 = 结论 → 证明（字母幻方 + 线和加权组合 + 通俗解释；
  对顶定理、中心定理、四角和定理、补线法等自动命名，复用时只引用）→ 运用 → 填后示意图。
- **正方形自适应格子**：填写区、证明区、DOCX 导出的格子均为正方形，边长随数字宽度自适应。
- **浏览/导出**：分页（◀▶/键盘←→）、一页全显、打印为 PDF、导出 `.docx`。

## 算法原理（简述）

n 阶幻方 = 线性方程组（各行/列/两对角线之和相等 = 幻和 S），全部填法构成线性空间 MS
（n≥3 维数 n²−2n）。格子 k 可由已知集合 K 唯一确定 ⟺ 坐标泛函 e_k 在 MS 上的限制
属于 {e_c}_{c∈K} 的张成。每步：搜索极小前提集（1~3 个已知数精确枚举，更大者贪心收缩）→
解出恒等式 `γ·x_k = Σ α_c·z_c`（由“线和=S”加权组合证明，证明文字由此生成）→ 代入数值，
与整体特解交叉校验。详见 `PROJECT-BRIEF.md`。

## 实现说明

- 有理数用 JS Number 存分子分母（|值| < 2^53 整数精确），每次运算约分 + 安全整数检查；
- 求解为协作式异步（每 ~12ms 让出主线程），大阶数不卡界面；
- 某些**开发版 Chromium**（如 156 dev）渲染器本身不稳定（纯忙循环/中等规模分配也会崩），
  与本应用无关；正式版 Chrome/Edge/Firefox 正常。
